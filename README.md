# Aplikasi Kas STM

Aplikasi pembukuan kas untuk STM (Serikat Tolong Menolong) — aplikasi desktop Windows
(termasuk Windows 7 32/64-bit) untuk satu bendahara, tanpa internet.

Baca `CLAUDE.md` lalu dokumen di `docs/` secara berurutan. Ringkas:

```bash
nvm use          # Node 20
npm install
npm run dev      # http://localhost:3000
npm test
```
