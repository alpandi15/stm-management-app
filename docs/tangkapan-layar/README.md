# Tangkapan Layar Aplikasi Kas STM

Diambil otomatis oleh `scripts/tangkap-layar.js` dari bundel Electron 22 / Node 16 dengan data
dummy `scripts/data-demo.js` (STM Setia Kawan Blok C, 40 anggota, 4 RT, 4 kejadian duka,
300+ catatan Jan–Sep 2026). Lebar 1366px (laptop) kecuali seri 70–73 (390px).

Cara membuat ulang: jalankan server standalone dengan `STM_DATA_DIR` kosong, lalu
`OUT=docs/tangkapan-layar STM_DATA_DIR=<folder> electron scripts/tangkap-layar.js`.
